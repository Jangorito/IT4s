## Summary

Herrington documents the design and construction of an interactive electro-acoustic instrument based on reacTable-style tangible interaction. The system interprets object movement and touch as musical control, using a pipeline that includes sensing, processing, response, mapping, and feedback. While the musical context differs from IT4s, the paper is useful as an example of interactive music system design where physical input is transformed into musical behaviour through layered technical subsystems.
