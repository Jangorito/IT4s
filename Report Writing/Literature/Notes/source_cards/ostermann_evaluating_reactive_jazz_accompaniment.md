## Summary

This paper evaluates EAR Drummer, a reactive system that generates drum accompaniment for jazz improvisation and adapts behaviour in real time using heuristic rules derived from the user's melodies. It compares the system with iReal Pro through a user study. The paper is highly relevant to IT4s because it combines jazz improvisation, automatic drum behaviour, real-time reaction, and evaluation of perceived creativity. It is not the same interaction model as IT4s, because it focuses on accompaniment rather than turn-based trading fours, but it provides strong evaluation context.
