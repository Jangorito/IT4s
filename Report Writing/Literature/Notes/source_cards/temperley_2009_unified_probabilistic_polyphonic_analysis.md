## Summary

Temperley presents a probabilistic model that analyses polyphonic symbolic music by jointly considering meter, harmony, and stream segregation. Rather than treating these as independent subtasks, the model frames them as interacting structures inferred from note patterns. This is useful for IT4s because it gives a precedent for treating rhythmic/musical interpretation as structured feature inference rather than as direct generation. The paper is broader and more harmony-focused than IT4s, but it supports the idea that computational musical systems can derive explicit intermediate representations before later decision-making.
