## Summary

Thom describes work toward Band-OUT-of-a-Box, a system intended to improvise with a live musician in a jazz/blues setting. The paper emphasises personalised improvisational companionship and the challenge of perceiving musical material in a way that can guide musically appropriate generation. It is especially useful for IT4s because it frames improvisation as a constrained, real-time activity in which the system must make decisions under temporal pressure.
