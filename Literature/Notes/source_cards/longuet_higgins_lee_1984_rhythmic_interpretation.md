## Summary

Longuet-Higgins and Lee analyse how listeners assign rhythmic interpretations to monophonic note sequences. The paper argues that rhythmic input is formally ambiguous but that listeners tend to interpret sequences through regular metrical assumptions and higher-level grouping. This is useful for IT4s because the system similarly resolves raw timing input into a structured symbolic pattern and later analyses metrical salience.
