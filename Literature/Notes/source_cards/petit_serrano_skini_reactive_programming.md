## Summary

Petit and Serrano present Skini, a programming methodology and execution environment for interactive structured music. The system uses synchronous reactive programming to balance deterministic musical composition with nondeterministic audience interaction. It is relevant to IT4s because it treats interactive music as a structured stateful process rather than as unconstrained output generation. This aligns with IT4s' use of explicit phases, event-driven orchestration, and constrained response planning.
