## Summary

Martin and Torresen propose IMPS, an interactive musical prediction system using mixture density recurrent neural networks to predict future user control data rather than symbolic notes. The paper argues that predictive models can support new interactive modes such as filling in missing control data or filtering user input. Its evaluation shows that real-time predictive interaction is viable even on modest hardware. For IT4s, this is a strong comparison point: IT4s does not implement an MDRNN or predictive model, but it addresses a related design space through explicit turn segmentation, feature analysis, and response planning.
