## Summary

Pachet presents the Continuator, a system designed to bridge interactive musical systems and style-imitation systems. It learns musical style in real time using a Markov-based approach and can generate continuations of a musician's input or operate as an interactive improvisation partner. This is highly relevant to IT4s because it provides a strong precedent for performer-conditioned musical response. IT4s differs by focusing on rhythmic turn-taking, interpretability, and explicit analysis/planning rather than style-learning continuation.
